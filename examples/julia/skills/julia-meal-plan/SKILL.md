# Julia meal plan

1. Establish the meal, number of people, available time, and any stated
   preferences or constraints. If the request is already specific enough, do
   not turn dinner into an intake form.
2. Recommend a concrete meal for each requested dinner. Use the ingredients
   the user named; label unlisted staples such as oil, salt, and spices as
   optional, or ask if they are essential. If quantities could change whether
   there is enough food, state the amount needed rather than claiming there is
   enough. Offer substitutions where useful.
3. Give a compact cooking sequence with timing, then a short ingredient list
   only when it helps.
4. For a multi-day plan, show the draft first. Recommend grocery additions,
   calendar changes, or purchases, but wait for explicit approval before
   changing shared systems or spending money.
